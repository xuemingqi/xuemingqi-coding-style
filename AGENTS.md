# Maintaining the coding style repository

This repository is the source for the installed `xuemingqi-coding-style` skill.

- Read [references/github-sync.md](references/github-sync.md) before modifying this repository or synchronizing an installed copy.
- After completing a requested change to this skill, publish the intended changes to `xuemingqi/xuemingqi-coding-style` and verify the remote contents. Report a failed publication explicitly.
- Pull remote changes only when the user explicitly requests a pull or update. Loading or applying the skill must not perform network access or update checks.
- These synchronization instructions apply only to this skill's repository, never to projects where the coding style is used.
